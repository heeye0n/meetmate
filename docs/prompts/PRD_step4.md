# Step 4 — F4 대시보드 + F5 회의 이력

## 목표
저장된 회의와 액션 아이템으로 팀 진행 현황을 보여 주고, 다음 회의를 추천한다.

## 할 일
1. `core/storage.py` 정리: 회의 목록, 액션 아이템 상태(할 일/진행 중/완료) 변경
2. `views/dashboard.py`
   - 상단 지표: 전체 할 일 수, 완료율, 마감 임박(3일 이내) 수
   - 팀원별 막대그래프 (할 일 수/완료 수)
   - 마감 임박 목록 (빨간색 강조), 상태 변경 체크박스
   - 회의 이력 타임라인 (날짜, 참석자, 결정 사항 수)
   - "다음 회의 안건 제안": 지난 회의의 미완료 할 일 목록
   - "다음 회의 잡기" 버튼 → 약속 잡기 페이지(views/schedule.py)로 이동 (가장 가까운 마감일을 기준 날짜로 전달)
3. 홈 화면(app.py)에 시연용 흐름 안내: ① 약속 잡기 → ② 회의록 정리 → ③ 대시보드

## 확인 방법
- 샘플 회의 2개를 저장한 뒤 대시보드 숫자가 맞는지 직접 계산해서 비교
