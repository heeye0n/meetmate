# MeetMate (밋메이트)

대학 팀플의 **약속 잡기 → 회의 → 할 일 정리 → 실행**을 한 곳에서 끝내는 AI 팀플 도우미.
인공지능활용실습 개인 텀프로젝트 (2026-2학기)

## 기능
1. **약속 잡기** — 카톡 대화를 붙여넣으면 팀원별 가능 시간을 뽑아 회의 시간 Top 3 추천 + 캘린더(.ics) 등록
2. **회의록 정리** — 할 일·담당자·마감일을 원문 근거와 함께 추출 (없는 정보는 지어내지 않음)
3. **GitHub 이슈 등록** — 검토한 할 일을 버튼 한 번으로 이슈로
4. **팀 대시보드** — 팀원별 진행률, 마감 임박, 다음 회의 안건
5. **회의 이력** — 지난 회의의 미완료 할 일 이어받기

## 실행
```
pip install -r requirements.txt
copy .env.example .env   # 키 입력
streamlit run app.py
```
